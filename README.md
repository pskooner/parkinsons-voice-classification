# Data directory

The original course-provided training and test datasets are not included in this public-ready repository.

To reproduce the analysis, place the authorized files here as:

- `pd_speech_features_trainPh1976.csv`
- `pd_speech_features_test_with-no-label_Ph1976.csv`

The analysis will also create processed files (`pd_train_v1.csv`, `pd_test_v1.csv`, `pd_train_v2.csv`, `pd_test_v2.csv`, and `pd_preprocessed.RData`) in this directory.

Before publishing any data, confirm that redistribution is permitted by the original data source/course materials.
